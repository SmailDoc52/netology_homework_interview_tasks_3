# Дополнительное задание №3: Рефакторинг кода (модуль работы с почтой)

Реализация обязательного задания на рефакторинг скрипта для отправки и получения писем в соответствии со стандартами PEP8 и требованиями технического задания.

## Важное примечание автора
Данная работа сфокусирована исключительно на **архитектурном рефакторинге** исходного кода: исправлении синтаксических ошибок, структурировании логики в класс, выносе конфигурационных данных и приведении именований к стандарту PEP8. Глубокий анализ внутренней логики работы библиотек `smtplib` и `imaplib` в рамках данной задачи не проводился — упор сделан на качественную переработку структуры «грязного» кода.

## Что было сделано (по ТЗ):
1. **Объектно-ориентированная структура:** Вся разрозненная логика исходного скрипта упакована в единый класс `EmailManager` (находится в модуле `tools/email_manager.py`).
2. **Разделение обязанностей:** Созданы два изолированных метода класса: `send_message` для формирования и отправки писем и `receive_message` для их поиска и получения.
3. **Безопасность и конфигурация (Убран хардкод):** Все захардкоженные учетные данные (логин/пароль) вынесены в переменные окружения и подтягиваются через модуль `python-dotenv`. Серверы и параметры отправки передаются как аргументы.
4. **Соответствие PEP8:**
   - Все переменные и методы переименованы в стиль `snake_case`.
   - Исправлены некорректные и двусмысленные имена переменных (например, `l`, `passwORD`).
   - Исправлены критические опечатки исходного кода (включая передачу аргументов в `sendmail`).
1. **Точка входа:** Инициализация класса и демонстрационный вызов методов обернуты в конструкцию `if __name__ == '__main__':` внутри файла `main.py`.

## Структура модулей задания:
```text
├── tools/
│   └── email_manager.py  # Отрефакторенный класс EmailManager со всей логикой
├── .env.example          # Шаблон для конфигурации переменных окружения
├── main.py               # Точка входа для запуска и демонстрации
└── requirements.txt      # Зависимости (python-dotenv)
```

## Инструкция по запуску:

1. Установите зависимость для работы с переменными окружения:
    
    Bash
    
    ```
    pip install -r requirements.txt
    ```
    
2. Создайте файл `.env` в корне проекта на основе `.env.example` и укажите свои данные:
    
    Фрагмент кода
    
    ```
    LOGIN=your_email@gmail.com
    PASSWORD=your_app_specific_password
    ```
    
    _(Примечание: Для авторизации в Gmail требуется использование "Пароля приложения", а не основного пароля аккаунта)._
    
3. Запустите скрипт:
    
    Bash
    
    ```
    python3 main.py
    ```
