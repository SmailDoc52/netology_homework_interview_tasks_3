## Важное примечание автора
Данная работа сфокусирована исключительно на **архитектурном рефакторинге** исходного кода: исправлении синтаксических ошибок, структурировании логики в класс, выносе конфигурационных данных и приведении именований к стандарту PEP8. Глубокий анализ внутренней логики работы библиотек `smtplib` и `imaplib` в рамках данной задачи не проводился — упор сделан на качественную переработку структуры «грязного» кода.

## Что было сделано (по ТЗ):
1. **Объектно-ориентированная структура:** Вся разрозненная логика исходного скрипта упакована в единый класс `EmailManager` (находится в модуле `tools/email_manager.py`).
2. **Разделение обязанностей:** Созданы два изолированных метода класса: `send_message` для формирования и отправки писем и `receive_message` для их поиска и получения.
3. **Безопасность и конфигурация (Убран хардкод):** Все захардкоженные учетные данные (логин/пароль) вынесены в переменные окружения и подтягиваются через модуль `python-dotenv`. Серверы и параметры отправки передаются как аргументы.
4. **Соответствие PEP8:**
   - Все переменные и методы переименованы в стиль `snake_case`.
   - Исправлены некорректные и двусмысленные имена переменных (например, `l`, `passwORD`).
   - Исправлены критические опечатки исходного кода (включая передачу аргументов в `sendmail`).
1. **Точка входа:** Инициализация класса и демонстрационный вызов методов обернуты в конструкцию `if __name__ == '__main__':` внутри файла `main.py`.

## Документация по классу EmailManager

Класс предназначен для централизованного управления отправкой (SMTP) и получением (IMAP) электронной почты.

### 1. Инициализация класса (`__init__`)
При создании экземпляра класса необходимо передать конфигурационные данные для подключения и авторизации.

**Параметры:**
* `mail_smtp` *(str)* — адрес SMTP-сервера (например, `"smtp.gmail.com"`).
* `mail_imap` *(str)* — адрес IMAP-сервера (например, `"imap.gmail.com"`).
* `login` *(str)* — логин (почтовый ящик) для авторизации.
* `password` *(str)* — пароль (или пароль приложения) для доступа к почте.

**Пример создания объекта:**
```python
email_mng = EmailManager("smtp.gmail.com", "imap.gmail.com", "login@gmail.com", "password")
```
### 2. Метод `send_message ` 
Отвечает за формирование структуры письма и его отправку через SMTP-протокол. Внутри метода автоматически используются контекстные менеджеры для безопасного открытия и закрытия сетевого соединения.

**Параметры:**
* `recipients` (list) — список строк с адресами получателей (например, `['user1@mail.com', 'user2@mail.com']`).
* `subject` (str) — тема отправляемого письма.
* `message_text` (str) — текстовое содержимое (тело) письма.

**Что делает:** Создает объект `MIMEMultipart`, заполняет заголовки (`From`, `To`, `Subject`), прикрепляет текст, подключается к серверу на порт 587, включает шифрование TLS, авторизуется и отправляет сообщение. В случае ошибки выводит уведомление в консоль.  

### 3. Метод `receive_message`
Отвечает за подключение к почтовому ящику по протоколу IMAP, поиск писем по заданному критерию и получение последнего из них.

**Параметры:**
* `folder` (str) — имя папки в почтовом ящике для поиска (например, `"INBOX"`).
* `header` (str, optional) — заголовок (тема письма) для фильтрации поиска. По умолчанию равен `None` (ищет все письма в папке).

**Что делает:** Подключается к IMAP-серверу через защищенное соединение SSL, выбирает указанную папку, формирует критерий поиска (по теме или `ALL`), находит UID последнего подходящего письма, запрашивает его сырые байты и преобразует их в объект `email.message` с помощью метода `message_from_bytes`. Если писем нет, возвращает `None`.

## Инструкция по запуску:

1. Установите зависимость для работы с переменными окружения:
    
    Bash
    
    ```
    pip install -r requirements.txt
    ```
    
2. Создайте файл `.env` в корне проекта на основе `.env.example` и укажите свои данные:
    
    Фрагмент кода
    
    ```
    LOGIN=your_email@gmail.com
    PASSWORD=your_app_specific_password
    ```
    
    _(Примечание: Для авторизации в Gmail требуется использование "Пароля приложения", а не основного пароля аккаунта)._
    
3. Запустите скрипт:
    
    Bash
    
    ```
    python3 main.py
    ```
